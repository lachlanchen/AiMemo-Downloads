# AiMemo downloads

Windows installers for [AiMemo](https://memo.lazying.art), a place for notes, voice messages and plans.

[Download the Windows preview](https://github.com/lachlanchen/AiMemo-Downloads/releases/download/windows-v1.0.0-preview/AiMemo-Setup-1.0.0-x64.exe) · [Setup and requirements](https://memo.lazying.art/windows.html) · [Open the web app](https://aimemo.lazying.art)

The Windows preview opens AiMemo in a dedicated Microsoft Edge window and profile. It requires Windows 10/11 x64 and Microsoft Edge. The installer is unsigned; if your device policy blocks unsigned apps, use the web app rather than disabling security.

This repository contains release downloads and user instructions only. The installer does not include source code, account data or credentials. Download the `.exe` asset, not GitHub's source-code archives. Compare it with `SHA256SUMS.txt` if needed.

The download is free. Existing AiMemo accounts and subscription terms do not change. See the [release notes](https://github.com/lachlanchen/AiMemo-Downloads/releases/tag/windows-v1.0.0-preview) for testing scope and known limitations.
